# KenPanel MailBridge

> High-performance email gateway, SMTP/IMAP bridge, and containerized mail engine for KenPanel.

## Components

- engine/ - Core email routing, DKIM/SPF/DMARC processing, and queue manager
- gateway/ - Inbound/Outbound SMTP and IMAP proxy services
- docker/ - Docker Compose and container recipes for isolated mail stacks
- config/ - Default configuration templates and DNS record presets
